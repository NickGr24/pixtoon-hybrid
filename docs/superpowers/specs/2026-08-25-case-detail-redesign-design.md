# Страницы кейсов по макету PIXTOON — дизайн

Дата: 2026-08-25. Заказ: две HQ-раскладки от клиента
(`PIXTOON_Microinvest_Case_Study_HQ.png` 2880×6700,
`PIXTOON_DriveGas_Case_Study_HQ.png` 2160×5175) задают новый вид страницы
кейса. Требование — так должны выглядеть все пять, обе локали.

## Что уходит

Блоки `Provocarea / Soluția / Producția / Rezultatul` — в макете их нет.
Тексты остаются в JSON как источник для новых формулировок, но на странице
не рендерятся. Секция «Următorul case study» заменяется на «Alte case
studies» — четыре карточки вместо одной ссылки.

## Каркас страницы

Одинаковый у всех пяти:

1. **Герой** — eyebrow `CASE STUDY — <БРЕНД>`, H1, outline-подзаголовок,
   лид, мета-таблица на 4 строки, кадр.
   Два варианта раскладки, выбор по формату материала кейса:
   - `portrait` — мета столбиком слева, вертикальный кадр 9:16 справа
     (Microinvest, Berea Chișinău);
   - `wide` — мета строкой в 4 колонки с разделителями, кадр 16:9 во всю
     ширину под ней (Drive Gas, Coccolino, Medpark).
2. **Панель преимуществ** — скруглённый блок с бледным сиреневым
   градиентом: заголовок по центру + 4 колонки (иконка в белом круге,
   лейбл, два ряда текста), разделители между колонками.
3. **Outline-фраза** — одиночный крупный заголовок, только outline.
4. **Секции контента** — массив, см. ниже.
5. **Alte case studies** — eyebrow, заголовок, 4 карточки остальных
   кейсов с бейджем и круглой стрелкой, ссылка «Vezi toate proiectele».
6. **CTA** — панель с тем же градиентом, заголовок, подзаголовок,
   золотая кнопка.

## Четыре типа секций

Закрытый список, снят с двух макетов. Кейс перечисляет только те, под
которые у него есть кадры.

| `type` | Форма | Поля |
|---|---|---|
| `characters` | заголовок + 3 карточки с чипом, подпись под рядом | `title`, `items[{img, chip}]`, `caption` |
| `mosaic` | сетка 7 слотов с бейджами | `items[{img, badge, span}]` |
| `split` | eyebrow, заголовок, картинка слева + карточка справа | `eyebrow`, `title`, `img`, `card{title, text, checks[]}` |
| `cards` | заголовок + 3 карточки с бейджем | `title`, `items[{img, badge}]` |

Раздача по кейсам:

| Кейс | Герой | Секции | Кадров |
|---|---|---|---|
| Microinvest | portrait | `characters` + `mosaic` | 7 |
| Drive Gas | wide | `split` + `cards` | 4 |
| Medpark — Doctor Buba | wide | `characters` + `mosaic` | 8 |
| Coccolino | wide | `split` + `cards` | 3 |
| Berea Chișinău | portrait | `split` + `cards` | 3 |

## Данные

`casesData.json` разбирается на `src/_data/cases/<slug>.json` — по файлу на
кейс. `cases.js` читает каталог, сортирует по `order` и отдаёт тот же
массив `featured`, что и раньше: `landing.njk`, `work.njk` и `home.njk`
не меняются.

Схема кейса дополняется веткой `page` внутри каждой локали:

```
{ slug, order, brand, media{...},        // как было
  hero: "portrait" | "wide",
  gallery: { ... },                       // пути к кадрам, вне локалей
  en: { title, tags, excerpt,             // как было
        challenge, solution, production, result,   // не рендерятся
        page: { subtitle, lead, meta[4], panel{title, items[4]},
                statement, sections[], related{...}, cta{...} } },
  ro: { ... то же ... } }
```

Пути к картинкам лежат вне локалей — кадр один на оба языка. Локаль несёт
только подписи к нему.

## Картинки

Источники — скриншоты кадров из роликов в `~/Downloads/Telegram Desktop`
(`Captură de ecran din 2026-08-13 la *.png`, 25 файлов, 1100–3400 px) и обе
HQ-раскладки. Соответствие «файл → слот» задаётся таблицей в
`tools/crop-cases.mjs`; скрипт режет, масштабирует и пишет
`src/assets/img/cases/<slug>/<slot>.jpg` плюс копии `-400`, `-800`.

Бейджи (`VIDEO 9:16`, `MAMA`, `BRANDING`) рисуются HTML-плашками поверх
кадра, а не запекаются в JPEG: иначе они не переводятся и мылятся при
масштабировании.

`i18n/*.json` под `caseStudy`. Кейс приносит кадры шагов и может переопределить
формулировки.

## Третий раунд: ролики и плеер (25.08, ночь)

### Источники роликов

| Кейс | Откуда |
|---|---|
| Drive Gas | `DRIVE GAS FINAL .mov`, мастер 4K из загрузок |
| Berea Chișinău | `BEER CHISINAU NEW VERTICAL.mov`, вертикальный мастер 4K |
| Microinvest | канал студии на YouTube, `UvWq7Vk_aF4` «Microinvest RO Family 30 sec» |
| Medpark — Doctor Buba | `DOCTOR BUBA FINAL.mp4`, мастер 4K HEVC |
| Coccolino | `LOCAL COCCOLINO.mov`, мастер 2560×1440 из загрузок |

Перекодирование — `tools/encode-videos.mjs`. Полный ролик: H.264 high, CRF 24,
потолок 2 Мбит/с, faststart, AAC 128k. Превью: 8 секунд, без звука, половинная
ширина, CRF 30. Вес: 6–12 МБ на полный, 0.3–0.6 МБ на превью.

Ссылка `tmNuqrVh-O0`, присланная клиентом, ведёт на «Joint Support Ultra» —
другую работу студии, не относящуюся ни к одному из пяти кейсов.

### Плеер

Нативный `controls` заменён своей панелью. Причина не в оформлении: кадр
кадрируется по контейнеру, а панель браузера рисуется внутри видео и уезжала
за границу фигуры — перемотать ролик было нечем.

Ползунок — `input[type=range]`: перемотка с клавиатуры, роль `slider` и
перетаскивание на тач-экране достаются бесплатно. Иконки состояний лежат в
разметке парами, показ переключает CSS; скрипт трогает только классы и
подписи. Контейнер при запуске подгоняет пропорцию под ролик.

Клавиши при фокусе на кадре: пробел / `K`, стрелки ±5 с, `M`, `F`.

Вес `hybrid.min.js` вырос с 4.2 до 6.8 КБ — половину занимает плеер.

### Отдельно про перемотку

Жалоба «нельзя перемотать» имела две независимые причины. Первая — панель за
границей кадра, исправлена. Вторая — `python -m http.server` отвечает `200` на
любой `Range`, и в такой раздаче перемотка не работает вообще, сколько бы её
ни чинили в коде. Для локальной проверки нужен сервер, отдающий `206`.

### Правки перевода (по замечанию клиента)

У Microinvest румынские метки мета-таблицы остались английскими — я перенёс
их с раскладки дословно, а там они были на английском: `Project`,
`Production`, `Deliverables` → `Proiect`, `Producție`, `Livrabile`.

Сквозная вычитка обеих локалей дала ещё девять правок. Существенные:
время глагола разошлось у Drive Gas (RO настоящее, EN прошедшее);
«not rigged» по-английски читается как риггинг персонажа, а не «свет не
выставляли» → `not staged`; «a range of motion» — медицинский термин →
`a variety of movements`; «an animated surgery» в американском чтении это
операция → `an animated clinic`; в румынском у Medpark смешались
«cast» и «distribuție».

### Блеск у крупной фразы

Три штриховых варианта подряд читались неверно: равные лучи из точки — как
стрелка «>», параллельные — как галочка, разведённые веером — как обломок
снежинки. Заменён на четырёхконечную звезду с вогнутыми лучами плюс
маленькую рядом, заливкой.

### Сжатие Medpark и удаление workflow

Ролик Medpark идёт 168 секунд — вчетверо дольше остальных, и на общих
настройках (1920, 2 Мбит/с) весил бы под 40 МБ. Прежний файл в репозитории
был 720p при 1 Мбит/с и 22.8 МБ; обещание «ужать вдвое» из прошлого отчёта
оказалось неверным — оно исходило из предположения, что файл 1080p.

Пережат из мастера при 1280 и 700 кбит/с → 16 МБ. Кадр на статике неотличим
от прежнего: мультипликация с плавным движением и мягкими градиентами жмётся
заметно лучше съёмки. Таблица `VIDEOS` теперь допускает свои `crf` и
`maxrate` на кейс.

`.github/workflows/deploy.yml` удалён. Он использовал `actions/deploy-pages`,
который работает только при `build_type: workflow`, а Pages здесь настроены
на ветку `gh-pages` (legacy). Workflow падал после каждого пуша в `main`,
ничего при этом не публикуя, и вводил в заблуждение красным крестиком.
Инструкция по обновлению демо в README переписана под worktree: прежняя
предлагала `cd dist && git commit`, хотя `dist/` лежит в `.gitignore`.

### Кадры в блоке абонементов

В секции «Ai nevoie de conținut în fiecare lună?» вторая карточка показывала
`doctor-buba-youtube.jpg` — скриншот интерфейса YouTube с боковым меню
браузера вместо кадра из работы. Первая показывала рекламный баннер с
надписью «PREMII MINUNATE», хотя блок называется «контент с персонажем».

Обе заменены на кадры из слота `pack` (16:10, 1200 px): у Coccolino медведь
крупным планом, у Medpark — трое персонажей в кабинете.

Попутно замечено: у карточек абонементов висит `data-hyb-hover-video`, но
внутри нет `<video>` — превью при наведении там не проигрывается, а кнопка
play декоративная. Не трогал, задача была про кадры.

### Обрезка кадров: пропорции, а не фокус

Клиент сообщил, что обрезано «процентов 80». Диагноз оказался не в промахах
фокусных точек, а в самих пропорциях слотов, взятых из раскладки: у клиента
под каждый слот был свой кадр, а у нас исходники Microinvest вертикальные
(600×1075), и голова занимает в них 54% высоты.

Измерено по кадру с процентной сеткой: мама 3–57%, отец 5–92% (в рост), дочь
12–48%, мама на кухне 20–45%, кухонная сцена 33–80% по вертикали и 28–75% по
горизонтали.

| Слот | Было | Стало | Почему |
|---|---|---|---|
| герой | 2.9 : 1 | 16 : 9 | панорама брала от вертикального кадра 19% высоты |
| карточка персонажа | 4 : 3 (42%) | 4 : 5 (70%) | голова в 54% не помещалась в принципе |
| шаг процесса | 4 : 3 | 1 : 1 (56%) | квадрат вмещает голову любого из портретов |
| боковая плитка | 2.4 : 1 (23%) | 4 : 3 (42%) | полоска резала голову сверху и снизу |
| кадр рассказа | 2.2 : 1 | 16 : 10 | то же в мягкой форме |

Добавлен параметр `top` — верхняя граница рамки долей высоты. Для портретов
это единственный надёжный способ: голова начинается на известной высоте, и
«прижать рамку сюда» проверяется глазом по кадру, тогда как точка интереса
требует пересчёта при каждой смене пропорции.

Попутно найдены два дефекта. Валидация слотов в `cases.js` смотрела только
`items`, но не `aside` и `slots` — пропавший слот боковой плитки дошёл до
страницы как `<img>` без `src`. И панель плеера висела поверх кадра до
запуска ролика: атрибут `hidden` даёт `display:none` из таблицы браузера, а
правило класса `.hyb-player { display: grid }` выше по специфичности.

### Дуги между шагами процесса

Пунктирные соединители ложились на последнюю строку текста. Две независимые
причины: зазор ряда 12px при ширине дуги 32px — она выходила за него и
заезжала на соседнюю карточку; и `bottom: 0.35rem` при тексте, доходящем до
самого низа карточки — свободной зоны под ним не было.

Ряд получил зазор 28px, карточка — отступ снизу 1.5rem, дуга встала ровно в
зазор и ниже текста. Колонка потеряла 11px из 244 — дешевле, чем декор,
который либо перечёркивает текст, либо не читается.

Работает и там, где у шагов нет кадров: колонки грида растягиваются до
высоты самой высокой, поэтому низ у всех карточек ряда общий и дуги встают на
одну линию независимо от числа строк.

### Microinvest приведён к общему составу

Панель преимуществ была убрана у Microinvest при переходе на вторую
раскладку — там её нет. Но остальные четыре кейса живут по первой раскладке,
где панель есть, и Microinvest оказался единственной страницей без неё.

Панель возвращена с текстами первой раскладки («Un univers de brand pregătit
să crească» и четыре колонки). Теперь состав у всех пяти одинаков:

    герой → панель → рассказ → процесс → сравнение → фраза →
    персонажи или карточки → итог → другие кейсы → призыв

Различия остались только там, где их диктует материал: у Microinvest шаги
процесса идут с кадрами (у остальных исходников на это не хватает), а
Microinvest и Medpark показывают персонажей, тогда как Drive Gas, Coccolino и
Bere — карточки кампаний.

## Пакет клиента от 29 августа 2026

`wep pagy hibrid .zip` — документ с полными текстами пяти страниц на румынском
и 21 файл материалов. Материал качественно другой: раньше присылали кадры из
готовых роликов, здесь — закулисье продакшена (записи экрана из Blender и
After Effects, playblast, turnaround-листы, снимок сцены в 3D-пакете) и три
реальные публикации кампании Drive Gas.

### Что изменил документ

**Позиционирование.** Отдельный редакционный раздел прямо говорит:
формулировки «Personaj AI» и «Produs AI» создают впечатление, что личность
бренда или продукт сгенерированы приблизительно. Обе такие метки на сайте
были — у Coccolino и Bere Chișinău.

Замена коснулась не только меток. Общие блоки `process` и `compare` рендерятся
на всех пяти страницах и говорили «Unde accelerăm cu AI» и «Accelerare prin
AI» — ровно та рамка, от которой документ уходит. Панель сравнения теперь
противопоставляет не человека и машину, а два места приложения метода: «Unde
lucrăm în 3D clasic» и «Unde lucrăm hibrid». Это и есть довод самого
документа: «Producția hibridă nu elimină 3D-ul clasic. Îl folosim exact acolo
unde aduce cea mai mare valoare».

Ключи `compare.human` и `compare.ai` переименованы в `classic` и `hybrid`:
оставленные прежними, они называли бы содержимое неверно в единственном месте,
где название и содержимое обязаны совпадать.

Лендинг раздела не тронут — документ его не просит, а его редакционный раздел
называется «Recomandări pentru pagina principală» и состоит из таблицы меток.

**Состав страницы.** Документ даёт всем пяти кейсам одинаковую структуру, и
порядок секций стал одинаковым: рассказ, перечень работ, процесс, сравнение,
фраза, кадры, итог, условия применимости. Два места документа —
«Ce am construit» и «Acest model poate funcționa pentru brandul tău dacă» —
это заголовок со списком, которого в наборе типов не было. Добавлен тип
`list`: с кадром он кладёт список в текстовую колонку, без кадра —
раскладывает его в две колонки справа от заголовка.

Довод «De ce am ales producția hibridă» у каждого кейса свой, а панель
сравнения общая. Поэтому панель получила заголовок с подводкой из данных
кейса — общее осталось общим, частное приехало из кейса.

**Название страницы Medpark.** Документ помечает вопрос как «de confirmat
înainte de publicare»: «Mafa Girafa», «Doctor Buba» или «Doctor Buba» —
название эпизода. Ролик на странице отвечает на него сам: жираф в халате из
кадров — это Mafa Girafa, а «Doctor Buba» написано в титрах эпизода. Страница
названа `Medpark — Mafa Girafa`, slug и папка кадров переименованы вслед за
названием, «Doctor Buba» осталось в текстах названием серии.

### Закулисные клипы

Записи экрана показывают метод буквально: моделирование бутылки по фотографии
референса, playblast против референсного кадра, риггинг жирафа в Blender. Это
сильнейший аргумент новых текстов, и стоп-кадр его теряет — на статике запись
экрана читается как скриншот, а не как работа.

Клип — девять секунд без звука, петлёй, запуск по появлению на экране. Девять,
а не двадцать: дальше петля начинает восприниматься как ролик, который зачем-то
не даёт себя перемотать.

Клипы лежат в папке кадров кейса под тем же именем, что их постер
(`clip-rig.mp4` рядом с `clip-rig.jpg`). Отдельный каталог заставил бы держать
имя слота синхронным в двух местах; здесь рассинхрон невозможен по устройству,
и `cases.js` проверяет оба файла одной проверкой.

Отрезки выбраны по раскадровке, а не с начала файла: у записи моделирования
первые секунды — пустой вьюпорт, у playblast первые кадры почти чёрные, и
клип оттуда читался бы как незагрузившееся видео.

Битрейт ограничен: у теста персонажа Coccolino медведь покрыт мелкими цветами,
и на общих 900 кбит/с клип упирался в потолок — мегабайт, который страница
качает сама, без спроса. 600 кбит/с дают 700 КБ при неразличимой на глаз
разнице.

### Материал, который не пошёл в дело

`COCOLINO/personaj-.png` — не готовый визуал акции, а рабочая сборка: слово
COCCOLINO наполовину закрыто лапой медведя, под ним зелёная подложка хромакея.
Целиком показать нельзя — обрезанное слово читается как брак; вырезать медведя
без слова тоже нельзя, по горизонтали они перекрываются. Механику кампании на
этой странице несёт `clip-test` из того же пакета.

`MICROINVEST/post micro.jpg` содержит один план дважды: сырой рендер слева,
после цвета справа. Правая половина нарезалась в слот рассказа, но на странице
осталась не у дел: герой показывает ту же семью на той же кухне, и два кропа
одной сцены на странице — это повтор, а не второй кадр.

### Мёртвый код

Тип секции `characters` (карточки персонажей с боковой колонкой плиток) после
пересборки не запрашивает ни один кейс. Убран из шаблона вместе со своим
блоком CSS; кадры `person-*` и `strip-*` удалены из рецепта нарезки и с диска.
Проверка «объявлено в CSS, но нет в разметке» прогнана после удаления — она же
ловила прошлую регрессию, когда вместе с мозаикой уехали общие `.hyb-cs__tile`
и `.hyb-cs__checks`.

### Очистка dist перед сборкой

Переименование кейса выявило дыру: `dist/` не чистился между сборками, и
страница `medpark-doctor-buba` пережила переименование. Каталог уезжает в
`gh-pages` целиком, так что удалённый URL продолжал бы отдавать старый текст
неограниченно долго. `npm run build` начинается с `rm -rf dist`.
